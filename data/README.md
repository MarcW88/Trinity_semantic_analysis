# Données du tableau de bord

Un dossier par marché : `BENL`, `BEFR`, `BEEN`. Déposez-y les fichiers Excel (`.xlsx`) au format Streamlit, puis commitez : Vercel redéploie et le tableau de bord se met à jour.

Le format des colonnes est décrit dans [docs/EXCEL.md](../docs/EXCEL.md). Un dossier vide affiche « Données à venir ».
